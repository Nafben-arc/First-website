## Run the website locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Keep `styles.css` in the same folder as `index.html`.

## Add your profile photo
1. Create an `images` folder in the project folder if it does not exist.
2. Copy your chosen photo into that folder.
3. Rename the photo to `profile.jpg`.
4. The expected path is `images/profile.jpg`.

If you do not add a photo, the page displays the initials NK instead.

## Publish with GitHub Pages
1. Push the project files to the `main` branch of the GitHub repository.
2. Open the repository on GitHub.
3. Select **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish the site.

Expected repository: https://github.com/Nafben-arc/personal-portfolio

Expected Pages address: https://nafben-arc.github.io/personal-portfolio/
